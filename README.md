# Hệ thống Thông tin Xã - Frontend (Next.js)

Hệ thống quản lý thông tin hành chính, tin tức và thủ tục cho cơ quan xã.

### Môi trường chạy dự án: Node.js v20.14.0

### Các bước cài đặt: (chế độ development)
1. Cài đặt thư viện: `npm i`
2. Cập nhật file `.env.development` (nếu cần thiết)
3. Chạy dự án: `npm run dev`

### Cách chạy tại chế độ production:
1. Cài đặt thư viện: `npm i`
2. Cập nhật file `.env.production` (nếu cần thiết)
3. Build dự án: `npm run build`
4. Chạy dự án: `npm run preview`
